# Neo Market B2B — Кабинет продавца

Модуль личного кабинета продавца для платформы Neo Market.

## 🚀 Cтарт

Для запуска проекта необходимо склонировать репозиторий и запустить контейнеры через Docker.

1. **Клонирование репозитория:**
   ```bash
   git clone https://github.com/tochka-tochka/neo_market
   cd neo_market
   ```

2. **Запуск через Docker Compose:**
   ```bash
   docker-compose up
   ```

---

## 🌐 Порты и сервисы

После запуска сервисы будут доступны по следующим адресам:

| Сервис | Порт | Описание |
| :--- | :--- | :--- |
| **Django API** | `8010` | Бэкенд часть приложения |
| **Frontend** | `3080` | Пользовательский интерфейс |
| **Minio API** | `9000` | S3-хранилище (API) |
| **Minio Web** | `9001` | Панель управления Minio (Console) |

---

## 🔑 Аутентификация и авторизация

В проекте реализована система авторизации на базе **JWT (JSON Web Token)** с использованием `djangorestframework-simplejwt`.

### 1. Регистрация нового пользователя
* **URL:** `http://localhost:8010/api/v1/reg/`
* **Метод:** `POST`
* **Тело запроса:**
    ```json
    {
        "username": "ваш_логин",
        "password": "ваш_пароль"
    }
    ```

### 2. Получение токена (Login)
* **URL:** `http://localhost:8010/api/v1/login/`
* **Метод:** `POST`
* **Тело запроса:** Аналогично регистрации. В ответе вы получите `access` и `refresh` токены.

## 📦 Функционал API

Помимо стандартных эндпоинтов из основной спецификации, реализованы следующие возможности:

### Товары и накладные
* **Просмотр:** Эндпоинты для получения списка **всех товаров** и **всех накладных** конкретного продавца.
* **Удаление:** Реализована возможность удаления следующих сущностей:
    * Товар
    * SKU (товарная позиция)
    * Накладная
* Также, можно создавать несколько накладных и примать их по id `http://localhost:8010/api/v1/invoices/<:invoice_id>/accept/`
